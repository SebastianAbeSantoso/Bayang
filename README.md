# Bayang: The Vanishing Caravans

Bayang is a tabletop-RPG-style learning experience for people beginning data analytics. In its first quest, players investigate caravan-loss records and discover why raw counts can tell a different story from rates when the group sizes differ.

## The experience

Players question characters, inspect a guild ledger, compare counts and rates, then choose a conclusion and support it with evidence. Apprentice mode provides more guidance; Pathfinder mode offers a less guided investigation. Both lead to the same analytics skill, followed by a short transfer challenge.

The initial audience is learners in a bootcamp, class, or self-guided course. Bootcamps and educators are the buyer hypothesis for a short, applied practice experience.

## AMD's role

An open-weight language model served on AMD Developer Cloud acts as the adaptive game master: it voices characters and responds to player choices with tailored clues. The app keeps story facts, calculations, game state, and answer checks deterministic.

## First-build scope

- One complete quest and one fixed dataset
- Two guidance styles
- A few character interactions and clue choices
- One evidence-backed conclusion and one transfer question
- Model inference only; no fine-tuning, accounts, multiplayer, or user-uploaded data
